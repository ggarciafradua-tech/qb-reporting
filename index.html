CDM USA

Aplicación interna de reportes contables

Puerto Patagonia LLC · IKI Midtown · Weston, Florida

CDM USA es una aplicación de uso interno que consulta la API de QuickBooks Online para generar reportes de gestión de dos sociedades operadas por el mismo grupo: IKI Midtown y Puerto Patagonia LLC.

No es un producto comercial. No se ofrece a terceros, no tiene usuarios externos y no procesa datos de clientes de otras empresas.

Qué hace

  • Trae estados de resultados, balances y reportes de gastos por proveedor.
  • Los combina con datos operativos de venta para el análisis de gestión mensual.
  • Opera en modo de solo lectura: no crea, modifica ni elimina ningún registro en QuickBooks.

Documentos

  • Términos de uso (EULA)
  • Política de privacidad

Desconectar la aplicación

La autorización se revoca desde QuickBooks Online, en Configuración → Aplicaciones → CDM USA → Desconectar, o escribiendo a la dirección de contacto. Al desconectarla, los tokens de acceso almacenados dejan de ser válidos de inmediato y se eliminan.
